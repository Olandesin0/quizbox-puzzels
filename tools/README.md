# Render-Skripte

SVG -> Playwright -> JPG im Thema "Antraciet & terracotta" (DM Sans).

- `puzzel_render.py <puzzels.json> <zielordner> [ids]` – Paardensprong/Taartpuzzel (Felder wie Blatt Puzzels)
- `verbanden_render.py <daten.json> <zielordner>` – Verbanden-Raster; `loesung()` für das Lösungsbild

Läuft auch auf dem Raspberry Pi (Python + Playwright/Chromium).
